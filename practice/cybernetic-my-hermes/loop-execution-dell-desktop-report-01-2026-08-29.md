### 迁移中修复的 3 个 Windows 适配 bug（WSL 原版在 desktop 不可直接用）

1. **编码崩溃**：`subprocess text=True` 默认本地编码，git 输出含中文文件名（GBK 字节）→ UnicodeDecodeError。修复：`encoding="utf-8", errors="replace"`
2. **cmd.exe 解析破坏**：`shell=True` 走 cmd.exe，`--format='%an <%ae>'` 中 `%an` 被当批处理变量展开、单引号无效 → 作者检查永远失败（假阴性）。修复：`shell=False` + 参数列表，彻底绕开 shell 解析
3. **显示缺陷**：未跟踪文件（`??`）不列入不干净清单 → 改为列出全部变更项 `[状态] 路径`

另增强：新仓库无提交时跳过作者检查（不假阳性）；作者期望值支持 `GIT_EXPECTED_AUTHOR` 环境变量覆盖。

### 实际验证（双向）

- **阻断分支**：在本项目仓库（工作区含未提交报告）运行 → exit 1，正确列出 `[??] practice/.../loop-execution-dell-desktop-report-01-2026-08-29.md`，作者检查正确通过
- **通过分支**：临时干净仓库（正确作者+干净工作区）运行 → exit 0，四项全 ✅

三重防护迁移完成，两部署防护标准现已一致。
